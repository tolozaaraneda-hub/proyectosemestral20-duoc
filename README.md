Descripción del Proyecto

Aplicación móvil nativa desarrollada en Kotlin para Android Studio, diseñada para la gestión de productos y servicios locales, La aplicación implementa arquitectura "MVVM (Model-View-ViewModel)", interfaz adaptativa con "Jetpack Compose" y persistencia de datos local para garantizar el funcionamiento correcto sin dependencia constante de red

---

Tecnologías y Herramientas Utilizadas

- Lenguaje: Kotlin
- UI Framework: Jetpack Compose (Material 3)
- Arquitectura: MVVM
- Control de Versiones: Git & GitHub
- Gestión del Proyecto: Trello (Metodología Ágil)

---

Funcionalidades Principales

- Pantalla de Inicio / Catálogo: Visualización de ítems y productos disponibles
- Formulario de Registro / Edición: Captura de datos con validaciones básicas de campos
- Persistencia Local: Guardado y lectura de información dentro del dispositivo
- Navegación: Flujo claro e intuitivo entre pantallas utilizando Jetpack Navigation
